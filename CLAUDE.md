# Signaly

A lean, accessible, 2D browser modular synthesizer. See `README.md` to run it and `docs/system-architecture.md` for how it fits together.

## Agent skills

### Issue tracker

Issues live as markdown files under `.scratch/<feature>/` in this repo — it has no git remote, so there is no GitHub or GitLab tracker to call. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage roles, each label string equal to its name. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` and `docs/adr/` at the repo root, created lazily when terms or decisions are actually resolved. See `docs/agents/domain.md`.
