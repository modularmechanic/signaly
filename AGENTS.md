# Signaly — agent configuration

The canonical agent configuration for this repo lives in [`CLAUDE.md`](./CLAUDE.md). This file exists so tools that look for `AGENTS.md` find it too.

Read `CLAUDE.md`, then the per-topic files it points at:

- `docs/agents/issue-tracker.md` — issues are local markdown under `.scratch/<feature>/`
- `docs/agents/triage-labels.md` — the five canonical triage roles
- `docs/agents/domain.md` — single-context domain docs (`CONTEXT.md`, `docs/adr/`)
